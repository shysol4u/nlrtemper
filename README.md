# NLR-Temper — Version 11

Public website files for the approved initial-testing release. Explore NLEEL-like motifs, domain position, reference context, and matching protein structures. Calls remain exploratory; independent predictive validation is not complete.

The website runs from this repository using GitHub Pages. The complete research source and its history remain in a separate private repository. Future releases will update these website files.

## Hosting notes

Local sequence analysis, reference examples, alignment, annotation import, structure inspection, and exports use the Version 11 modules. Automatic InterProScan requires a job email and service availability. NCBI CDD requires a server endpoint and is disabled in this static hosting edition. Historical comparison snapshots are preserved exactly; their original CDD controls require a server host.

## Scientific references

- Zhu et al. (2010): https://doi.org/10.1371/journal.ppat.1000844 — allele-specific temperature evidence.
- Grech-Baran et al. preprint: https://doi.org/10.64898/2025.12.17.694812 — interdomain/interface mechanism motivates inspection; the supplied shorthand grammar is exploratory and is not a verified reproduction of the published classifier.
- Kourelis et al. (2021), RefPlantNLR: https://doi.org/10.1371/journal.pbio.3001124 — reference sequences and computational domain/repeat annotations.
- Hewitt et al. (2025): https://doi.org/10.1038/s41467-025-60030-x — Sr6 temperature-response evidence.

Author names are not feature brands in the website interface; attribution and methodological limitations remain in these references and the versioned rules.
