Automatic domain prediction

Choose NCBI CDD, InterProScan, or both. Domain calls return here automatically and update the architecture. Results retain their source so you can compare the services. Runtime depends on the service queue.

CDD sends each protein sequence to NCBI; InterProScan sends the sequence and job email to EMBL-EBI. CDD uses E-value ≤ 0.01. One sequence runs at a time; jobs may take several minutes. Keep this tab open. Failed or pending jobs do not establish domain absence.

Advanced: import existing annotations

Analyze your FASTA first, then load existing HMMER or InterProScan results. This optional import is independent of the automatic services above. Protein identifiers and lengths must match; JSON additionally requires exact sequences.

HMMER imports retain independent domain E-values ≤ 1e-5. Generic signature spans, including LRR and protein kinase, are shown with their source; they are not automatically converted into numbered repeats. JSON format and coordinate guidance
